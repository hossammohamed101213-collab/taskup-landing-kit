# حزمة نسخة احتياطية: موقع TaskUp (إدارة العملاء والمشاريع والدفعات)

نسخة كاملة من الموقع كما وصل لحد دلوقتي، مع البرومبت اللي يعيد بناءه لخدمة تانية باسم تاني..

## الأسرع: افتح `START-HERE.html`

دوس عليه مرتين (بيفتح في المتصفح، من غير إنترنت)، املا اسم الموقع ونوع الخدمة، دوس **«انسخ البرومبت»**، الصقه في Claude Code (أو أي نموذج بيقدر يشتغل على ملفات) **وارفق معاه ملف الحزمة zip**. النموذج هو اللي يفكّ الملف ويشغّل كل الأوامر ويكتب المحتوى، ومش مطلوب منك تشغّل حاجة. باقي الملفات تحت للمرجعية.

## اللي جوّه

```text
START-HERE.html              ملف تدوس عليه: خانات + زرار «انسخ البرومبت» (من غير أوامر)
README.md                    الملف ده
PROMPT.md                    البرومبت الدقيق لإعادة الإنشاء (متغيّرات + برومبت رئيسي + فحص + أخطاء شائعة)
PLACEHOLDERS.md              كل رقم أو ادعاء مؤقت في النسخة الحالية لازم يتراجع قبل النشر
rebrand.py                   سكربت يغيّر الاسم والبادئات والدومين والواتساب في ثانية
site/                        الموقع كامل (index.html + portal.css + portal.js + robot/)
  robot/                     الروبوت ثلاثي الأبعاد (Three.js r180 محلياً في robot/vendor)
single-file/                 نسخة في ملف HTML واحد (محتاجة إنترنت للـ Three.js والخطوط)
content/CONTENT-INVENTORY.md كل نص ظاهر (عربي/إنجليزي) بمفاتيحه: دي قايمة اللي لازم يتكتب لأي خدمة جديدة
screenshots/                 لقطات من الموقع للمرجعية
```

## تشغيل الموقع على جهازك

الروبوت بيستخدم وحدات ES فلازم سيرفر محلي (مش فتح الملف مباشرة):

```bash
cd site
python3 -m http.server 8080
# افتح http://localhost:8080
```

نسخة `single-file/taskup-single-file.html` تتفتح بالضغط المزدوج، لكن محتاجة إنترنت.

## نشره

أي استضافة ملفات ثابتة تنفع: ارفع مجلد `site/` كما هو (GitHub Pages، Netlify، Cloudflare Pages، Vercel كموقع ثابت). في المشروع الأصلي كان موجود في `public/landing/` داخل تطبيق Next.js، يعني بيتفتح على `/landing/index.html`.

## تغيير الاسم بسرعة

```bash
python3 rebrand.py --src site --out my-site --name "Nova Hub" --word-a nova --word-b hub \
  --slug novahub --domain novahub.io --prefix NH --cprefix CM \
  --whatsapp 201112223334 --phone "+20 11 1222 3334"
```

بيغيّر الاسم الظاهر، وجزئي الشعار، ومعرّفات الكود (`window.novahubLang`…)، وبادئات أرقام الطلب والشكاوى، والإيميلات، والواتساب. **مش بيغيّر المحتوى** (البطاقات والأسئلة وبيانات البوابة): ده بتعمله مع البرومبت.

اتجرّب فعلاً: النسخة المعاد تسميتها اشتغلت (روبوت حي، رقم طلب `NH-G-…`) من غير أخطاء.

## إزاي تعيد الإنشاء لخدمة تانية

1. افتح `PROMPT.md` واملا المتغيّرات (القسم 1).
2. افتح مشروع جديد في Claude Code، وارفق `site/` كمرجع، والصق القسم 2.
3. خليه يمشي قائمة الفحص (القسم 4).

## حالة النسخة: إيه حقيقي وإيه تجريبي

**شغّال فعلاً:** كل الواجهة والحركات والروبوت (الإمساك بالمؤشر والنوم والصحيان)، عربي/إنجليزي، نموذج طلب فتح حساب بالتحقق، أرقام الطلب والشكاوى بألوان الباقات، التتبّع المحلي، الشكاوى، بوابة العميل التجريبية.

**تجريبي أو مؤقت (محتاج خادم لو عايزه حقيقي):**

- الطلبات والشكاوى بتتحفظ في متصفح العميل بس، وبتوصلك لما العميل يضغط «ابعت على واتساب». مفيش قاعدة بيانات ولا لوحة إدارة.
- حالة التتبّع بعد «اتبعت لفريقنا» (مراجعة، فتح حساب…) ما بتتحدّثش لوحدها.
- بوابة العميل بحساب تجريبي واحد (`TU-2481`) وبيانات ثابتة. الدفع والشات تجريبيين.
- الأرقام العشوائية للطلبات ممكن تتكرر نظرياً من غير خادم يضمن التفرّد.
- كلام الموقع عن تكاملات (Meta/Google/TikTok/متاجر/API) ووظائف (فواتير، تذكير تلقائي…) هو **وصف منتج** لسه ما اتبنيش. راجع `PLACEHOLDERS.md`.
